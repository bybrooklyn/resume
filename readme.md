# Resume

This repository contains my resume written in LaTeX.

## Files

* `resume.tex` — LaTeX source for the resume
* `readme.md` — README for the GitHub repo
* `license.txt` — the license for this project

## Building

To compile the resume, run:

```bash
pdflatex resume.tex
```

Or, if you want it to rebuild automatically while editing:

```bash
latexmk -pdf resume.tex
```

## Requirements

You need a LaTeX distribution installed, such as:

* TeX Live
* MacTeX
* MiKTeX
